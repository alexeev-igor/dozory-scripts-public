# Политика конфиденциальности Dozory Tools

Дата вступления в силу: 29 августа 2026 года

## 1. Общие положения

Dozory Tools — браузерное расширение, предназначенное для улучшения интерфейса браузерной игры Dozory.ru.

Расширение работает только на страницах:

- `http://game.dozory.ru/*`;
- связанных игровых ресурсах `st.dozory.ru`, используемых для отображения элементов интерфейса.

Dozory Tools является неофициальным расширением и не связано с администрацией Dozory.ru.

## 2. Какие данные обрабатывает расширение

Для выполнения заявленных функций расширение может локально обрабатывать содержимое открытых страниц Dozory.ru, в том числе:

- сведения об игровых предметах и домашнем сейфе;
- содержимое игровых окон и Торговой галереи;
- сведения о лабиринте;
- ссылки и данные журналов боёв, необходимые для синхронизации таймеров;
- идентификатор игрового персонажа, когда он необходим для выполнения выбранного пользователем игрового действия;
- другие элементы текущей игровой страницы, необходимые для работы включённых модулей.

Расширение не получает доступ к истории посещений за пределами Dozory.ru.

Расширение не читает и не сохраняет пароли, платёжные данные или данные банковских карт. Оно также не использует файлы cookie напрямую.

## 3. Локально сохраняемые настройки

В хранилище браузера локально сохраняются:

- включённое состояние модулей;
- выбранная сортировка Умного сейфа;
- шаблоны автокаста;
- настройки карты лабиринта.

Эти настройки используются исключительно для работы расширения.

Они не передаются разработчику, рекламным сервисам или аналитическим платформам.

## 4. Использование игровых данных

Содержимое страниц Dozory.ru обрабатывается исключительно для предоставления функций расширения:

- группировки и сортировки предметов;
- выполнения выбранных пользователем игровых действий;
- отображения карты лабиринта;
- поиска по Торговой галерее;
- синхронизации игровых таймеров.

Данные не используются для рекламы, профилирования пользователей, аналитики, оценки кредитоспособности или продажи третьим лицам.

## 5. Передача данных

Dozory Tools не имеет собственных серверов и не передаёт игровые данные разработчику.

Некоторые функции расширения выполняют необходимые запросы к `game.dozory.ru` от имени пользователя. Например, такие запросы используются для получения содержимого Торговой галереи, карты лабиринта, журналов боёв и выполнения выбранных игровых действий.

Эти запросы направляются только игровой инфраструктуре Dozory.ru в рамках существующей игровой сессии пользователя.

Расширение не передаёт данные рекламным сетям, аналитическим сервисам, брокерам данных или другим посторонним организациям.

## 6. Хранение и удаление данных

Настройки расширения хранятся локально в браузере до тех пор, пока пользователь не изменит их или не удалит расширение.

Настройки карты лабиринта могут сохраняться в локальном хранилище сайта `game.dozory.ru`. Их можно удалить очисткой данных сайта в настройках браузера.

Для удаления остальных локальных данных пользователь может удалить расширение или очистить его данные через настройки браузера.

## 7. Доступ разработчика к данным

Разработчик Dozory Tools не получает, не хранит и не просматривает игровые данные пользователей.

В расширении отсутствуют:

- системы аналитики;
- рекламные SDK;
- отслеживание действий пользователя;
- удалённое журналирование;
- передача телеметрии разработчику.

## 8. Ограниченное использование данных

Использование информации, полученной через API браузера, соответствует политике пользовательских данных Chrome Web Store, включая требования Limited Use.

Данные используются только в объёме, необходимом для предоставления заявленных пользовательских функций расширения.

## 9. Изменения политики

При изменении способов обработки данных эта политика может быть обновлена. Актуальная версия всегда публикуется по тому же адресу.
